# Roadmap

- [x] Impedir que o pedido de notificações reapareça depois de aceito e renovar a inscrição silenciosamente.
- [x] Medir engajamento por visita e atividade no app, não por login ou cadastro; incluir planos Empresariais no painel.
- [x] Permitir pesquisar no Backs Radar sem plano Executivo e mostrar apenas a contagem de oportunidades e convite para upgrade, sem expor contatos.
- [x] Fazer a pesquisa respeitar o plano escolhido mesmo em uma conta administradora, mantendo liberações individuais explícitas.
- [x] Permitir ao administrador apagar a região cadastrada no Backs Radar para o artista configurar novamente.
- [x] Permitir corrigir o CEP salvo do Radar quando a cidade foi configurada com um CEP inválido.
- [x] Integrar a base pública do BacksAI ao Backs Radar com cache local, sem Google na busca.
- [x] Usar a base própria de oportunidades já armazenadas.
- [x] Filtrar contatos exatamente por CEP/região, raio e categorias selecionadas.
- [x] Selecionar todas as categorias inicialmente e permitir removê-las.
- [x] Exibir todos os resultados armazenados, sem corte de 1.000 registros.
- [x] Validar a busca do Backs Radar e o bloqueio do plano Executivo.
- [x] Restringir resultados a locais com oportunidade real para música ao vivo.
- [x] Permitir selecionar qualquer cidade do estado definido pelo CEP e bloquear outros estados.
- [x] Preencher cidades selecionadas a partir da base do BacksAI quando faltarem registros locais.
- [x] Importar e deduplicar sob demanda os contatos das cidades pesquisadas, por local e categoria.
- [ ] Validar o fluxo autenticado de Cruzeiro e São José dos Campos, CRM e bloqueio do plano Executivo. Bloqueio: projeto externo sem sessão de teste autenticada.
