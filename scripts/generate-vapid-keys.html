🔑 Gerador de Chaves VAPID

Gere um par de chaves VAPID compatíveis com Web Push (incluindo Apple Safari iOS)

📋 Instruções após gerar as chaves:

  1. Copie cada valor gerado acima
  2. No Lovable, atualize os secrets:
    • VAPID_PUBLIC_KEY - cole a chave pública
    • VAPID_PRIVATE_KEY - cole a chave privada
    • VAPID_SUBJECT - use mailto:seuemail@dominio.com
  3. Importante: Após atualizar os secrets, você precisa pedir aos usuários para reativar as notificações pois as chaves antigas não funcionarão mais
